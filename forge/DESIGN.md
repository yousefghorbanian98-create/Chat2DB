## ۱) حال‌وهوا و بافت بصری — **کارگاه** (نسخه‌ی ۲)

کارگاه یعنی «جایی که کار در آن انجام می‌شود»: روشن، گرم، با فضایِ نفس‌کشیدن.
برخلافِ ویرایشگر که صفحه ساکت می‌ماند، اینجا رابط **دعوت می‌کند** — عنوان‌های
بزرگ، کارت‌های لایه‌لایه، و فاصله‌های سخاوتمندانه.

| اصل | معنی |
|---|---|
| گرمی | زمینه‌ی کاغذیِ گرم، نه سفیدِ سرد و نه مشکیِ آبی |
| لایه | کارت روی کارت؛ هر لایه یک پله روشن‌تر |
| فضا | بینِ بخش‌ها ۴۸–۸۰px؛ بینِ عناصرِ یک گروه ۱۲–۱۶px |
| صدا | عنوان‌های ۳۶/۲۶ واضح‌اند، اما تزئینی نیستند |

**قانونِ تغییرناپذیرِ نسخه‌ی ۱ که حفظ شده:** هیچ سایه‌ای نیست. «بالا آمدن»
در کارگاه با جابه‌جاییِ ۲px، تغییرِ حاشیه و تغییرِ سطح ساخته می‌شود، نه با
سایه. (دلیل: قانون در نسخه‌ی ۱ گذاشته شد و هم‌چنان معتبر است؛ و گیتِ FE-4-G2
اجرایش می‌کند.)

## ۳) قواعد تایپوگرافی

نمایشی همیشه **وزن ۴۰۰**. مونو روی هر سطحِ کد.

| توکن | اندازه / وزن / ارتفاع / فاصلهٔ حروف |
|---|---|
| `display-lg` | ۳۶px / ۴۰۰ / ۱٫۲ / −۰٫۷۲px |
| `display-md` | ۲۶px / ۴۰۰ / ۱٫۲۵ / −۰٫۳۲۵px |
| `display-sm` | ۲۲px / ۴۰۰ / ۱٫۳ / −۰٫۱۱px |
| `title-md` | ۱۸px / ۶۰۰ / ۱٫۴ |
| `body-md` | ۱۶px / ۴۰۰ / ۱٫۵ |
| `body-sm` | ۱۴px / ۴۰۰ / ۱٫۵ |
| `caption-uppercase` | ۱۱px / ۶۰۰ / ۱٫۴ / ۰٫۸۸px |
| `code` | ۱۳px / ۴۰۰ / ۱٫۵ — JetBrains Mono |
| `button` | ۱۴px / ۵۰۰ / ۱٫۰ |
| `nav-link` | ۱۴px / ۵۰۰ / ۱٫۴ |

فونت‌ها: Inter (متن) و JetBrains Mono (کد) — هر دو از طریق Google Fonts.

> **یادداشتِ اجرا:** این جدول تا ۲۰۲۶-۰۹-۰۲ فقط روی کاغذ بود — کامپوننت‌ها
> اندازه‌ی دلخواه (`text-[22px]` و …) داشتند. از این تاریخ هر ردیفِ بالا به‌صورت
> یک utility در `src/styles/index.css` پیاده‌سازی شده (`text-display-md`،
> `text-body-sm`، `text-caption`، `text-code` و …) و تستِ رندر وجودِ
> اندازه‌ی دلخواه در خروجی را خطا می‌گیرد.

## ۴) استایل قطعات

- **شعاع:** کارت ۱۶px · کنترل (دکمه/ورودی) ۱۰px · چیپ ۸px · قرص کامل
- **دکمهٔ اصلی:** نارنجیِ برند، شعاعِ کنترل، ارتفاع ۴۰px
- **دکمهٔ ثانویه:** سطحِ کارت + خطِ موییِ ۱px
- **کارت:** سفید روی زمینه‌ی کاغذی، خطِ مویی، **بدون سایه**
- **«بالا آمدن» (hoverِ کارت):** جابه‌جاییِ ۲px + حاشیه‌ی قوی‌تر + سطحِ قوی‌تر
- **قرصِ مرحله:** فقط برای مراحلِ عامل و نشان‌ها — شعاعِ pill
- **فیلد ورودی:** سطحِ کارت + خطِ مویی، ارتفاع ۳۶px، درونِ یک کارتِ ۱۶px

## ۵) اصول چیدمان

مقیاسِ فاصله با پایهٔ ۴px:
`xxs ۴ · xs ۸ · sm ۱۲ · base ۱۶ · md ۲۰ · lg ۲۴ · xl ۳۲ · xxl ۴۸ · section ۸۰`

سه ستون در حالت دسکتاپ: فهرست (ثابت ۲۸۰px) · جریانِ اصلی (منعطف) · پنلِ کناری (۳۶۰px، قابل بستن).

## ۶) عمق و ارتفاع

**بدون سایه.** لایه‌بندی فقط با تضادِ سطح‌ها و خطِ مویی:

1. تخت / کف
2. پنل
3. کارت
4. کارتِ معکوس (برای موردِ برجسته)

## ۷) بایدها و نبایدها

**باید**
- هر رنگ از توکن بیاید، نه از مقدارِ ثابت در کد
- کد همیشه با JetBrains Mono
- مراحلِ عامل با پاستیل‌های تایم‌لاین
- وزنِ نمایشی ۴۰۰ بماند

**نباید**
- سایه (box-shadow) برای عمق
- استفاده از پاستیل‌های تایم‌لاین خارج از نمایشِ مراحل
- بولد کردنِ عنوان‌های نمایشی
- رنگِ مستقیم در کلاس‌ها (مثل `text-[#f54e00]`)

## ۸) رفتار واکنشی

| نام | عرض | تغییر |
|---|---|---|
| موبایل | < ۶۴۰px | ستون‌ها جمع می‌شوند؛ پنلِ کناری تمام‌صفحه |
| تبلت | ۶۴۰–۱۰۲۴px | پنلِ کناری به صورت لایه روی محتوا |
| دسکتاپ | ۱۰۲۴–۱۲۸۰px | سه ستون کامل |
| عریض | > ۱۲۸۰px | محتوا تا ۱۴۴۰px محدود می‌شود |

هدفِ لمسی: دکمهٔ اصلی ۴۰px، دکمهٔ دانلود ۴۴px.

## ۹) راهنمای پرامپت برای عامل

هر قطعهٔ UI جدید باید:
1. رنگ‌ها را فقط از توکن‌های بالا بخواند
2. مراحلِ عامل را با پاستیل‌های تایم‌لاین نشان دهد
3. بدون سایه باشد
4. عنوان‌های نمایشی را با وزن ۴۰۰ نگه دارد
5. کد را با JetBrains Mono نمایش دهد

## ۱۰) حرکت — جدولِ زمان‌بندی (نسخه‌ی کارگاه)

| رویداد | مدت | easing | حرکت |
|---|---|---|---|
| ورودِ صفحه‌ی آغاز | ۴۸۰ms | `cubic-bezier(.16,1,.3,1)` | محو + بالا آمدنِ ۱۲px، عناصر با ۶۰ms تأخیرِ پشت‌سرهم |
| کارتِ شروع‌کننده (hover) | ۲۴۰ms | `cubic-bezier(.34,1.56,.64,1)` | بالا آمدنِ ۲px + حاشیه‌ی قوی‌تر |
| ورودِ پیام | ۳۲۰ms | `cubic-bezier(.16,1,.3,1)` | محو + بالا آمدنِ ۱۰px |
| نقطه‌های جریان | ۱۲۰۰ms تکرار | `cubic-bezier(.4,0,.6,1)` | سه نقطه با ۱۶۰ms اختلافِ فاز |
| باز شدنِ پنل | ۳۲۰ms | `cubic-bezier(.34,1.56,.64,1)` | مقیاس ۰٫۹۶→۱ |
| جابه‌جاییِ تب | ۲۸۰ms | همانِ spring | نشانگر با spring می‌لغزد |
| فشردنِ دکمه | ۱۲۰ms | `ease-out` | مقیاس ۰٫۹۷ |
| تعویضِ تم | ۳۲۰ms | `ease-in-out` | محوِ متقاطع |
| فوکوس | ۰ms | — | حاشیه‌ی ۲px برند (بی‌درنگ، برای دسترسی) |

سه قانون:
1. **هیچ حرکتِ تزئینی** — هر انیمیشن یا ورود است، یا تأیید، یا جابه‌جایی.
2. `prefers-reduced-motion` همه‌ی حرکت‌ها را به محوِ ساده تبدیل می‌کند.
3. هیچ انیمیشنِ مکانی با easingِ خطی (گیتِ FE-4-G3).
