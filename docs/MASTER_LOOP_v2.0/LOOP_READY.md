# LOOP FILE — محل اجرای حلقه

فایل اجرای حلقهی یکپارچهسازی سوییچ پکیج موشن آماده است.

محل فایلها:

```
chat2db-community-client/scripts/master-loop/run-loop.cjs
chat2db-community-client/scripts/master-loop/verify-switch.mjs
chat2db-community-client/docs/master-loop/README.md
```

این فایلها فقط آماده شدهاند؛ هیچ گیتی اجرا نشده است.

حلقه با فرمان صریح زیر شروع میشود:

```
لوپ را شروع کن
```

جزئیات کامل گیتها در این فایل است:

```
chat2db-community-client/docs/master-loop/README.md
```
