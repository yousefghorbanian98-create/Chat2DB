### تصمیم

**کف را در میدل‌ور نگذار. در لایهٔ *پس از* مسیریابی بگذار، جایی که تایپ معلوم است.** الگوی الزامی (امضای `ApiError` از `app/errors.py:13-19` گرفته شده — آرگومانِ اول `message` است):

```python
# app/id_floor.py
from fastapi import Request

from app.errors import ApiError


def guard_id_floor(request: Request) -> None:
    """کفِ شناسهٔ مسیر: پس از مسیریابی، چون request.path_params از قبل coerce شده است."""
    for _name, value in request.path_params.items():
        if isinstance(value, int) and not isinstance(value, bool) and value < 1:
            raise ApiError(
                "شناسهٔ مسیر خارج از بازهٔ مجاز است.",
                status_code=422,
                code="invalid_id",
            )
```

ثبت به‌عنوانِ وابستگیِ سراسری: `FastAPI(dependencies=[Depends(guard_id_floor)], …)`. چون `request.path_params` **پس از** مسیریابی پر می‌شود، مقادیرِ `int` واقعاً `int` هستند و شش پارامترِ رشته‌ای هرگز لمس نمی‌شوند ⇒ **صفر مثبتِ کاذب**، بدونِ ۵۹ ویرایشِ امضا.

دو شرطِ **الزامی**:

۱. پاسخ باید **۴۲۲ با `error.code == "invalid_id"`** باشد. دلیلش خودِ پراب است (خطوطِ ۱۰۸–۱۱۱):

```python
if cls == "reached_4xx" and "invalid_id" in (text or ""):
    findings["id_guard_rejections"].append(...)
```

⇒ اگر کدِ دیگری برگردانی، گیتِ دومِ بسته («`id_guard_rejections` به ۴× تعدادِ مسیرهای پارامتردار برسد») هرگز پر نمی‌شود، هرچند رفتار درست باشد. همین `BODY` را که `app/id_guard.py` برمی‌گرداند (`code: "invalid_id"`، ۴۲۲) نگه دار تا دو لایه یک شکل بگویند.

۲. ماتریسِ آزمون **هر چهار** مقدارِ مشخصات را داشته باشد: `-1`، `0`، `-0`، INT64_MIN. در پایتون `int("-0") == 0` ⇒ با همان `value < 1` گرفته می‌شود؛ INT64_MIN هم چون int پایتون کران ندارد سالم می‌رسد و `< 1` است.

### اصلاحِ رسمیِ سندِ خودم

الگویی که در ردیفِ ۱۲۸ برنامه پیشنهاد داده بودم («مقدار را با `lstrip("+-")` بسنج، `int()` بگیر») **غلط است**: اگر `int()` روی رشتهٔ `lstrip`‌شده اعمال شود، `"-1"` به `"1"` تبدیل و **پذیرفته** می‌شود — یعنی دقیقاً خلافِ هدف. صورتِ درستِ همان گزینهٔ میدل‌وری: `lstrip("+-")` **فقط برای تشخیصِ عددی‌بودن**، و `int()` روی **رشتهٔ اصلی** تا علامت حفظ شود. با این حال آن گزینه دیگر توصیه نمی‌شود (به دلیلِ شش پارامترِ رشته‌ای).

### گزینهٔ جایگزین (بهتر از نظرِ تایپ، گران‌تر — بیرون از WP 3.1)

`PathId` در `app/deps.py:39` از قبل `Annotated[int, Path(ge=1, le=MAX_SAFE_ID)]` است و در **۰** امضای روتر استفاده شده. اعمالش در **۵۹** امضا + گذاشتنِ همان پویشِ AST به‌عنوانِ گیتِ رگرسیون (تا این عدد دیگر رشد نکند) اصلاحِ ریشه‌ای است. توجه: خودِ `app/id_guard.py:14-16` می‌گوید این راه «نیاز به تغییر ۴۱ امضا دارد» و عقب افتاد ⇒ آن بدهی امروز از ۴۱ به **۵۹** رسیده است. اگر این مسیر را انتخاب کردی، به‌عنوانِ یک بستهٔ **جدا** و با `AD-n` ثبت کن، نه داخلِ WP 3.1.
