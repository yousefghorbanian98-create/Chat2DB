# استودیو تحلیل محتوای یوتیوب

داشبوردی برای فهمیدن اینکه **کدام ویدیوهای یک کانال می‌ترکند و چرا** — تا برای محتوای خودتان ایده بگیرید.

بدون هیچ وابستگی npm نوشته شده. فقط Node.js لازم است.

---

## اجرای سریع (۳۰ ثانیه)

```bash
cd yt-studio
node server.js
```

بعد مرورگر را روی `http://localhost:3000` باز کنید و روی دکمه‌ی **«اجرای دمو با داده‌ی نمونه»** بزنید.
بدون کلید API هم کل داشبورد کار می‌کند و می‌توانید ببینید چه چیزی تحویل می‌گیرید.

---

## اتصال به داده‌ی واقعی یوتیوب

برای تحلیل کانال‌های واقعی، به یک کلید رایگان از **Google Cloud Console** نیاز دارید.

### قدم به قدم

1. به [console.cloud.google.com](https://console.cloud.google.com) بروید و با اکانت گوگل وارد شوید.
2. بالای صفحه، کنار لوگو، روی انتخابگر پروژه کلیک کنید → **New Project** → اسمی مثل `yt-studio` بگذارید → **Create**.
3. مطمئن شوید همان پروژه‌ی جدید انتخاب شده است.
4. منوی سه‌خط سمت چپ → **APIs & Services** → **Library**.
5. در جستجو بنویسید `YouTube Data API v3` → رویش کلیک کنید → دکمه‌ی آبی **Enable**.
6. حالا به **APIs & Services** → **Credentials** بروید.
7. بالای صفحه: **+ Create Credentials** → **API key**.
8. کلید ساخته‌شده را کپی کنید (چیزی شبیه `AIzaSy...`).

### گذاشتن کلید در پروژه

```bash
cd yt-studio
cp .env.example .env
```

فایل `.env` را باز کنید و کلید را بچسبانید:

```
YOUTUBE_API_KEY=AIzaSyXXXXXXXXXXXXXXXXXXXXXXXXX
PORT=3000
```

سرور را دوباره اجرا کنید:

```bash
node server.js
```

اگر پیام `✅ کلید YouTube API پیدا شد` را دیدید، همه‌چیز آماده است.

> ⚠️ فایل `.env` را هرگز در Git کامیت نکنید — در `.gitignore` قرار داده شده است.

## سهمیه‌ی رایگان

گوگل روزانه **۱۰٬۰۰۰ واحد** رایگان می‌دهد. مصرف هر عملیات:

| عملیات | هزینه |
|---|---|
| پیدا کردن کانال با `@handle` یا لینک | ۱ واحد |
| پیدا کردن کانال با **نام** (جستجو) | ۱۰۰ واحد |
| گرفتن هر ۵۰ ویدیو | ۲ واحد |

یعنی تحلیل یک کانال با ۱۵۰ ویدیو از روی handle تقریباً **۷ واحد** خرج دارد — روزانه بیش از هزار بار می‌توانید تحلیل کنید.

**نکته:** همیشه `@handle` یا لینک کامل کانال را وارد کنید، نه فقط اسم؛ ۱۰۰ برابر ارزان‌تر است.
نتایج هم ۱۰ دقیقه کش می‌شوند تا سهمیه هدر نرود.

## داشبورد چه چیزی نشان می‌دهد؟

### 💡 ایده‌های محتوا
- **عنوان‌های پیشنهادی** — ساخته‌شده از ترکیب کلیدواژه‌ها و قلاب‌هایی که در همان کانال بهترین عملکرد را داشته‌اند
- **ایده‌های Shorts** — پربازده‌ترین ویدیوهای بلند + زاویه‌ی پیشنهادی برای تبدیلشان به کلیپ کوتاه
- **کلیدواژه‌های برنده** — واژه‌هایی که وقتی در عنوان می‌آیند بازدید بالاتر می‌رود

### 🚀 ویدیوهای منفجرشده
معیار اصلی **«ضریب»** است: بازدید روزانه‌ی ویدیو تقسیم بر میانه‌ی کانال.
«×۳.۲» یعنی این ویدیو روزانه ۳.۲ برابر ویدیوی متوسط این کانال بازدید می‌گیرد.

چرا این معیار بهتر از بازدید خام است؟ چون ویدیوی دو سال پیش طبیعتاً بازدید بیشتری جمع کرده — ضریب، سن ویدیو را خنثی می‌کند. Shorts و ویدیوهای بلند هم جدا از هم مقایسه می‌شوند تا نتیجه منصفانه باشد.

### ✍️ الگوی عنوان‌ها
۱۰ قلاب ساختاری (عدد در عنوان، سوالی، هشدار/اشتباه، راز، مقایسه‌ای، تجربه شخصی و…) سنجیده می‌شود و می‌بینید کدام‌یک در آن کانال بالای ۱ است.

### 🕐 زمان و طول
بهترین روز هفته، بهترین بازه‌ی ساعت انتشار، و طول ایده‌آل ویدیو بر اساس داده‌ی خود کانال.

### 📋 همه ویدیوها
جدول قابل مرتب‌سازی و جستجو + خروجی **CSV** برای تحلیل در اکسل.

## ⚖️ نکته‌ی حقوقی

این ابزار فقط **آمار عمومی** را از YouTube Data API می‌خواند: عنوان، بازدید، لایک، تاریخ، مدت.
ویدیویی دانلود نمی‌کند و محتوایی کپی نمی‌کند.

دانلود و بازنشر ویدیوی کانال‌های دیگر:
- خلاف [شرایط استفاده‌ی یوتیوب](https://www.youtube.com/t/terms) است
- نقض کپی‌رایت است و به **strike** و در نهایت **بسته‌شدن کانال** منجر می‌شود
- درآمدزایی (monetization) کانال شما را از بین می‌برد

از این تحلیل‌ها برای فهمیدن **الگوی موفقیت** و ساخت محتوای **اورجینال خودتان** استفاده کنید. این همان کاری است که همه‌ی یوتیوبرهای حرفه‌ای می‌کنند.

## ساختار پروژه

```
yt-studio/
├─ server.js           سرور HTTP (بدون فریم‌ورک)
├─ .env.example        نمونه‌ی فایل تنظیمات
├─ lib/
│  ├─ youtube.js       کلاینت YouTube Data API v3
│  ├─ analyze.js       موتور تحلیل (ضریب، قلاب‌ها، کلیدواژه، زمان‌بندی)
│  └─ sample.js        داده‌ی نمونه برای حالت دمو
└─ public/
   ├─ index.html
   ├─ style.css
   └─ app.js
```

## عیب‌یابی

| پیام | راه‌حل |
|---|---|
| `کلید API نامعتبر است` | کلید در `.env` را دوباره چک کنید؛ فاصله یا کوتیشن اضافه نباشد |
| `YouTube Data API v3 فعال نشده` | قدم ۵ راهنمای بالا — دکمه‌ی Enable |
| `سهمیه‌ی روزانه تمام شد` | تا فردا صبر کنید یا از handle به‌جای جستجوی اسم استفاده کنید |
| `کانالی پیدا نشد` | به‌جای اسم، لینک کامل یا `@handle` را وارد کنید |
| پورت اشغال است | در `.env` مقدار `PORT` را عوض کنید |
