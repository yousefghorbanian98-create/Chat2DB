۹) تعریف انجام‌شده
PASS فقط وقتی: AC همان کارت رعایت شده + تست/گیت روی همین SHA اجرا شده + خروجی ثبت شده +
بدون regression (lint/build/test همان حوزه و همسایه‌ها) + مجوز سمت سرور آزموده شده (هرجا نقش دخیل است) +
سند/handoff به‌روز.
PASS نیست: mock یا fallback، screenshot تنها، تست skip‌شده، CI روی commit دیگر، «صفحه هست»، «API هست» بدون نقش/مالکیت،
و هر ادعایی که خودت اجرا نکرده‌ای. وضعیت میانی را PARTIAL بگذار با دلیل باقی‌ماندهٔ دقیق.
subagent یا review مستقل را ادعا نکن؛ اگر خودت اجرا نکردی بنویس «مرور دستیِ ایجنت اصلی».
