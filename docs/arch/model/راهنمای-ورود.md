# ورودِ مدل به برنامهٔ رندر

`model.obj` — یکا **متر**، محورِ **Z رو به بالا**، مبدأ در **گوشهٔ جنوب‌غربیِ زمین**.
۵۹ گروه با نامِ گویا (مثلِ `FLOOR_3_WEST_WING` یا `FLOOR_2_BALCONY_E`) و ۱۲ مصالح.
ابعادِ مدل: X ۰–۴۰٫۵۷ · Y ۰–۱۵٫۸۷ · Z ۰–۲۰٫۹۰ متر.

## تنظیمِ وارد کردن در هر برنامه

| برنامه | مسیر | نکتهٔ مهم |
|---|---|---|
| **D5 Render** | File → Import → Model | مستقیم درست می‌آید (Z-up) |
| **Twinmotion** | Import → انتخابِ OBJ | مستقیم درست می‌آید |
| **SketchUp** | File → Import | مستقیم درست می‌آید (SketchUp هم Z-up است) |
| **Blender** | File → Import → Wavefront (.obj) | در پنلِ سمتِ راستِ وارد کردن: **Up = Z** و **Forward = -Y** را بزنید، وگرنه ساختمان خوابیده می‌آید |
| **3ds Max / Lumion / Revit** | Import | Z-up استاندارد — درست می‌آید |

## کارِ پیشنهادی پس از ورود
1. به هر گروه مصالحِ واقعی بدهید (نما: تراورتن یا آجرِ نما · نردهٔ ایوان: شیشه · مغازه: شیشهٔ شفاف)
2. زمین را با تصویرِ ماهواره‌ای بپوشانید (در `geo/aerial_z19.jpg` بستهٔ کامل هست)
3. خورشید را روی **اصفهان، ۳۲٫۶۳ شمالی / ۵۱٫۷۲ شرقی** بگذارید
4. درخت، آدم و ماشین اضافه کنید — بیشترین تفاوتِ رندرِ آماتور و حرفه‌ای همین است

> این مدل «حجم‌هایِ خام» است (بدونِ بازشوهایِ خالی). برایِ رندرِ حرفه‌ای، پنجره‌ها را
> رویِ نما اضافه کنید — یا از فایلِ `CAD/final-plan.dxf` به‌عنوانِ زیرِانداز استفاده کنید.
