# 🔑 راهنمای گام‌به‌گام گرفتن کلید Nemotron از سایت NVIDIA

هر کلمهٔ انگلیسی و عدد مهم در سطر جدا نوشته شده است.

## مرحله ۱ — ورود به سایت
مرورگر را باز کنید و به این آدرس بروید:
```
https://build.nvidia.com
```

## مرحله ۲ — ساخت حساب کاربری
در بالا سمت راست صفحه، روی دکمهٔ زیر کلیک کنید:
```
Sign In
```
سه راه دارید: ثبت‌نام با ایمیل، یا ورود با:
```
Google
```
یا:
```
Microsoft
```

## مرحله ۳ — تأیید ایمیل
اگر با ایمیل ثبت‌نام کردید، صندوق پستی را باز کنید و لینک تأیید را بزنید.
با گوگل وارد شدید؟ این مرحله را ندارید.

## مرحله ۴ — رفتن به صفحهٔ مدل
در جستجوی سایت تایپ کنید:
```
nemotron
```
و این مدل را باز کنید (مغز پیش‌فرض برنامه):
```
nemotron-3-super-120b-a12b
```

## مرحله ۵ — گرفتن کلید
راه اول: در صفحهٔ مدل دکمهٔ:
```
Get API Key
```
راه دوم: آیکون حساب در بالا-راست → بخش:
```
Setup
```
→ دکمهٔ:
```
Generate API Key
```

## مرحله ۶ — کپی و نگه‌داری کلید
کلید شبیه این است:
```
nvapi-XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX
```
- کپی کنید و جایی امن ذخیره کنید — مثل رمز بانکی
- رایگان است

## مرحله ۷ — قراردادن کلید در لوپ (n8n)
روی هر نود شروع‌شده با:
```
run-19-
```
دو بار کلیک و در ابتدای فرمان اضافه کنید:
```
export CE_NVIDIA_API_KEY=nvapi-کلید-شما
```

## مرحله ۸ — آینده: داخل خود برنامه
بعد از پیاده‌سازی فاز ۱۹:
```
Settings → AI → NVIDIA
```

## نکته‌های مهم
۱ — کلید را عمومی نکنید (گیت‌هاب/تلگرام/اسکرین‌شات).
۲ — کلید لو رفت؟ در بخش:
```
Setup → API Keys
```
حذف و کلید جدید بسازید.
۳ — آفلاین = برنامه از «اندازه‌گیری‌های محلی» جواب می‌دهد؛ هیچ‌وقت از کار نمی‌افتد.
