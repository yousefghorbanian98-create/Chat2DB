# 10 — زنجیرهٔ ابزار متن‌باز: کدام، کجا، چرا

> شما فهرست بلندی از ابزارها و مخازن دادید. این سند هرکدام را **ارزیابی** می‌کند و
> می‌گوید کجای پروژه جا دارد — یا چرا ندارد.
>
> **اصل حاکم:** ابزارها به دو لایهٔ کاملاً جدا تقسیم می‌شوند و هرگز مخلوط نمی‌شوند.

```
┌─────────────────────────────────────────────────────────┐
│ لایهٔ A — میز کار توسعه‌دهنده / CI                        │
│ کمک به سرعت و کیفیت ساخت. هرگز داخل نصب‌کنندهٔ باشگاه.    │
└──────────────────────┬──────────────────────────────────┘
                       ▼
┌─────────────────────────────────────────────────────────┐
│ لایهٔ B — محصول Muscle Paradise (آنچه به مشتری می‌رسد)    │
│ FastAPI :8751 · React · SQLite · JP7 · Ollama اختیاری    │
└─────────────────────────────────────────────────────────┘
```

**قانون طلایی:** هر چیزی که به لایهٔ B اضافه می‌شود باید از سه فیلتر بگذرد:
۱) کار آفلاین؟ ۲) مجوز مجاز (نه GPL/AGPL)؟ ۳) هزینهٔ حجم/پیچیدگی توجیه‌پذیر؟
اکثر آیتم‌های فهرست شما در فیلتر ۱ یا ۲ رد می‌شوند — و این **خبر خوبی** است،
چون معنایش این است که محصول ساده و قابل نگهداری می‌ماند.

## 3. پل n8n — طراحی درست (از قبل پیاده شده ✅)

مخزن Zie619 با ۴٬۳۴۳ گردش‌کار MIT و جست‌وجوگر محلی، بهترین انتخاب فهرست شماست
[1](https://grokipedia.com/page/n8n-workflows_GitHub_repository).

**قرارداد سخت:**
```json
{ "event": "membership.expiring", "gym_id": 1, "member_id": 42,
  "days_left": 3, "ts": "2026-09-06T06:00:00Z", "sig": "hmac-sha256..." }
```
هیچ نام، تلفن، وزن، درصد چربی یا مصدومیت. n8n **جست‌وجو** می‌کند اگر لازم شد
(با توکن محدود)، ولی MP هرگز PHI را push نمی‌کند.

سه گردش‌کار اول برای پیاده‌سازی:
1. `membership.expiring` → پیامک/تلگرام یادآوری تمدید؛
2. `attendance.absent_14d` → هشدار به مربی برای تماس؛
3. `backup.failed` → هشدار فوری به مالک.

**و تستی که سند ۰۸ §۴.۳ می‌خواهد** تا این قرارداد هرگز نشکند.

## 4. Ollama — تنها AI مجاز در محصول

| قاعده | دلیل |
|-------|------|
| محلی، اختیاری، و قابل خاموش‌شدن | C1: بدون اینترنت هم کار کند |
| هرگز عدد تولید نمی‌کند | C6: JP7/TDEE ریاضی قطعی است |
| همیشه با موتور قاعده مسابقه می‌دهد | C7: اگر بدتر بود، قواعد برنده |
| خروجی از فهرست سفید عملیات عبور می‌کند | جلوگیری از تزریق پرامپت |
| سقف زمان و توکن | مدل کند نباید درخواست را قفل کند |

مدل پیشنهادی برای PC معمولی باشگاه: `qwen2.5:3b-instruct` یا `gemma2:2b` —
روی CPU با ۸GB RAM قابل اجراست. مدل بزرگ‌تر یعنی محصولی که روی سخت‌افزار مشتری کار نمی‌کند.

## 5. سیاست افزودن وابستگی

قبل از هر `pip install` یا `npm i` جدید، این فرم را در PR پر کنید:

```
نام بسته:
لایه (A یا B):
مجوز:                     (اگر GPL/AGPL و لایه B → رد خودکار)
حجم افزوده (gzip):
آیا آفلاین کار می‌کند؟
چه چیزی را حذف می‌کند؟    (اگر «هیچ» → احتمالاً لازم نیست)
جایگزین دست‌ساز چقدر کد است؟
```

سابقهٔ خوب پروژه: `python-bidi` به‌خاطر LGPL-3.0 رد و با ۸۰ خط MIT جایگزین شد.
**همین انضباط را ادامه دهید.** هر وابستگی، یک تعهد نگهداری ۵ ساله است.
