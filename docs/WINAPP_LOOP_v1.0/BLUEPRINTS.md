## قالب A — «ارکستریتورِ سبک» ⭐ پیشنهادِ اولِ من

**یک‌خطی:** پوستهٔ باریک، سه ابزارِ اصلی را به‌عنوان فرآیندِ جدا صدا می‌زنیم. کمترین کدِ سفارشی، سریع‌ترین رسیدن به یک چیزِ واقعاً کارکن.

```
┌─────────────────────────────────────────────────┐
│ Tauri 2  (WebView2 روی ویندوز)                   │
│  └── UI: React + Tailwind 4 + DaisyUI 5 + Motion │
├─────────────────────────────────────────────────┤
│ Node sidecar  (Hono، REST + SSE روی 127.0.0.1)   │
│  ├── JcodeAdapter   → subprocess: jcode SDK/CLI  │
│  ├── SoupAdapter    → subprocess: python soup    │
│  ├── GodmodeAdapter → خواندن skills/ از دیسک     │
│  └── McpClient      → ۱۰ سرورِ Godmode           │
└─────────────────────────────────────────────────┘
```

| منبع | جایگاه |
|---|---|
| Jcode | هستهٔ اجرا — subprocess، حافظهٔ معنایی و Swarm دست‌نخورده |
| Godmode | ۹ دستور به‌صورت فایل‌های `skills/*.md` + ۱۰ سرور MCP |
| Soup | لایهٔ انتخابِ skill قبل از هر فراخوانی مدل |
| مدل | OAuth خودِ jcode (Claude/OpenAI/Gemini/Copilot) |
| طراحی | DESIGN.md + DaisyUI 5 + Motion + Originkit برای تکه‌های خاص |

- ✅ سریع‌ترین مسیر · کیفیتِ هر سه ابزار دست‌نخورده · به‌روزرسانیِ هر کدام مستقل
- ⚠️ روی دستگاه مقصد باید Python 3.12+ و Node 22+ و jcode نصب باشد
- 🔁 قابل‌تعویضِ بعدی: Soupِ پایتونی → پیاده‌سازی TS (بدون تغییر در UI)

## قالب B — «هستهٔ خودکفا» (Monolith)

**یک‌خطی:** هیچ پیش‌نیاز خارجی. همه‌چیز در TypeScript؛ فقط یک نصب‌کنندهٔ ویندوزی تحویل می‌دهیم.

```
┌─────────────────────────────────────────────────┐
│ Electron (یا Tauri بدون sidecar)                 │
│  └── UI: React + Tailwind 4 + Motion             │
├─────────────────────────────────────────────────┤
│ هستهٔ یکپارچه (TypeScript)                        │
│  ├── Harness خودمان (الهام از jcode: ابزار، حافظه)│
│  ├── Router خودمان (الگوریتمِ Soup: BM25 + تگ)    │
│  ├── Skill loader (فرمت استاندارد SKILL.md)       │
│  └── McpClient (همان ۱۰ سرور)                     │
└─────────────────────────────────────────────────┘
```

| منبع | جایگاه |
|---|---|
| Jcode | **فقط الهام** — کدش را کپی نمی‌کنیم، معماری‌اش را یاد می‌گیریم |
| Godmode | فایل‌های skill مستقیماً مصرف می‌شوند (فرمت یکی است) |
| Soup | پورتِ منطق مسیریابی به TS (وابستگی پایتون حذف می‌شود) |
| مدل | کلاینتِ مستقیم OpenAI/Anthropic-compatible |

- ✅ یک نصب‌کننده، بدون پیش‌نیاز · کنترل کامل · مناسب توزیع برای دیگران
- ⚠️ بیشترین تلاش · از jcode/soup عقب می‌مانیم (نگه‌داری بر عهدهٔ ماست)
- 🔁 قابل‌تعویضِ بعدی: اگر بعداً خواستی، jcode را به‌عنوان backend اضافه کن

## قالب C — «کارخانهٔ عامل‌ها» (Finn-loop محور)

**یک‌خطی:** محصولِ اصلی，**خودِ فرآیند** است. Finn-loop می‌چرخد، Swarmِ jcode کار می‌کند، اپ فقط داشبوردِ نظارت است.

```
┌─────────────────────────────────────────────────┐
│ داشبوردِ نظارت (وب روی localhost → بعداً Tauri)   │
│  صفِ کار · وضعیتِ هر عامل · هزینه · گیتِ تأیید      │
├─────────────────────────────────────────────────┤
│ Finn-loop                                        │
│  /finn-spec → /finn-build → /finn-review         │
│       ↓ لیبل agent-ready        ↑ verdict         │
│  ┌─────────────────────────────────────────┐    │
│  │ Swarm: worker-1 … worker-N  (jcode)      │    │
│  │ هر کدام روی worktree جدا، حلِ تعارض خودکار│    │
│  └─────────────────────────────────────────┘    │
└─────────────────────────────────────────────────┘
```

| منبع | جایگاه |
|---|---|
| Finn-loop | ستون فقرات: spec → build → review، merge فقط با انسان |
| Jcode | موتور اجرا + Swarm برای کارِ موازی |
| Godmode | `/judgment` و `/sanctify` به‌عنوان گیتِ بازبینی |
| Soup | هر worker فقط skillهای مرتبط را می‌گیرد (صرفه‌جویی توکن) |
| طراحی | گیتِ «ضدکلیشه» با taste-skill قبل از پذیرش هر PR |

- ✅ اگر هدف این است که «خودِ برنامه را عامل‌ها بسازند»، این درست‌ترین قالب است
- ⚠️ ارزشِ آن در فرآیند است؛ ممکن است محصولِ نهایی دیرتر دیده شود
- 🔁 بعداً همان هسته را می‌توان داخل قالب A یا B گذاشت

│   G-design-2  taste-skill    → ضد خروجیِ کلیشه‌ای  │

              ↓ بعد از تثبیتِ ظاهر

└─────────────────────────────────────────────────┘

| منبع | جایگاه |

| awesome-claude-design / design-md-chrome | تولید DESIGN.md اولیه |

- ✅ بالاترین کیفیتِ بصری · هر ابزارِ طراحی بعداً هم به کارت می‌آید
- ⚠️ رسیدن به «اپِ کارکن» دیرتر است
