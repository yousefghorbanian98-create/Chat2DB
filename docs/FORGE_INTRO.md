# Forge — این برنامه چیست و چه می‌کند؟

> این متن برای این نوشته شده که بتوانید همان‌طور که هست برای دیگران بفرستید.

---

## اگر فقط ۳۰ ثانیه وقت دارید

**Forge یک برنامهٔ رومیزیِ ویندوزی (رایگان و متن‌باز) است که چند ابزارِ کدنویسیِ هوش‌مصنوعی — jcode، Soup و Godmode — را به‌جای چند ترمینالِ پراکنده، در یک پنجرهٔ واحد و راست‌به‌چپ جمع می‌کند.** در آن یک چت دارید، ۹ فرمانِ آماده دارید (`/genesis` برای ساخت قابلیت، `/exorcise` برای پیداکردنِ علتِ شکستِ تست، `/judgment` برای بازبینیِ Pull Request و …)، و وقتی جملهٔ ساده می‌نویسید برنامه خودش تشخیص می‌دهد کدام مهارت به دردِ شما می‌خورد.

---

## ۱. مشکلِ اصلی چیست؟

ابزارهای کدنویسیِ هوش‌مصنوعیِ متن‌باز هر کدام خوب‌اند، اما پراکنده: یکی در یک ترمینال است، یکی با فرمان‌های خاص صدا زده می‌شود، یکی مجموعه‌ای از پرامپت‌های آماده دارد که باید از فایل کپی شوند. نتیجه این است که بخش زیادی از وقت صرفِ «یادآوریِ اینکه کدام ابزار کجاست» می‌شود، نه خودِ کار.

Forge این لایهٔ پراکنده را برمی‌دارد: یک پنجره، یک چت، و فرمان‌هایی که همیشه در دسترس‌اند.

## ۲. دقیقاً چه کار می‌کند؟

### گفت‌وگو
یک چتِ راست‌به‌چپ با پاسخِ جریانی: پیام شما فوراً نمایش داده می‌شود و پاسخ تکه‌تکه و زنده می‌رسد (نه اینکه منتظر بمانید تا تمام شود). سشن‌ها در پنلِ کناری ذخیره می‌شوند و می‌توانید به گفت‌وگوهای قبلی برگردید.

### ۹ فرمانِ آماده (Slash Commands)
به‌جای نوشتنِ پرامپتِ تازه هر بار، فرمان‌ها ثابت و تکرارپذیرند:

| فرمان | کِی به کار می‌آید |
|---|---|
| `/genesis` | ساخت یک قابلیتِ جدید از صفر |
| `/exorcise` | پیدا کردنِ علتِ شکستِ یک تست |
| `/judgment` | بازبینیِ یک Pull Request |
| `/revelation` | توضیح دادنِ یک کدبیس یا بخشی از آن |
| `/covenant` | تعیینِ قراردادها و استانداردهای پروژه |
| `/prophecy` | پیش‌بینیِ ریسک‌ها قبل از شروع |
| `/sanctify` | پاک‌سازی و یکدست‌سازیِ کد |
| `/gospel` | مستندسازی و انتقالِ دانش |
| `/summon` | فراخوانی و ترکیبِ عامل‌ها |

### انتخابِ خودکارِ مهارت
لازم نیست نامِ فرمان را بدانید. اگر بنویسید «چرا تستم fail می‌شود؟»، برنامه با جست‌وجوی متنی روی مجموعهٔ ۱۴ مهارت، `/exorcise` را انتخاب می‌کند. اگر جمله بی‌ربط باشد، امتیازی نمی‌گیرد و چیزی تحمیل نمی‌کند.

### ۵ عاملِ تخصصی
`arbiter`، `demiurge`، `inquisitor`، `oracle`، `seer` — هر کدام نقشی در تحلیل و اجرا دارند و بسته به نوعِ درخواست به کار گرفته می‌شوند.

### جزئیاتِ رابط
تمِ روشن/تاریک، پالتِ فرمان (Command Palette)، طراحیِ مینیمالِ بدونِ سایه با رنگ‌های محدود به متغیرهای طراحی — یعنی ظاهر یکدست می‌ماند و هر رنگی از یک منبع می‌آید.

## ۳. زیرِ پوست (برای مخاطبِ فنی)

- **پوسته:** Tauri 2 با WebView2 — نصب‌کننده سبک می‌ماند و خبری از Electron و بستهٔ ۲۰۰ مگابایتی نیست.
- **رابط:** React + Vite + TypeScript + Tailwind 4، با یک سندِ طراحی (`DESIGN.md`) به‌عنوان مرجع که سه گیتِ خودکار آن را enforce می‌کنند: رنگ فقط از متغیرها، بدون سایه، بدون انیمیشنِ خطی.
- **سرورِ داخلی:** یک سرور Node در کنار برنامه اجرا می‌شود (خودِ `node.exe` داخلِ نصب‌کننده است). برنامه یک پورتِ آزاد پیدا می‌کند، سرور را بالا می‌آورد و تا آماده‌شدنش صبر می‌کند — یعنی کاربر با پورت یا تنظیمات کاری ندارد.
- **آداپتورها:** برای هر ابزارِ خارجی (jcode، Soup، Godmode، MCP) یک آداپتور هست که وضعیتش را با `ready` / `degraded` / `missing` گزارش می‌کند. **اگر ابزاری نصب نباشد برنامه نمی‌شکند**؛ فقط آن بخش غیرفعال می‌شود و بقیه کار می‌کنند.

> **نکتهٔ مهم و صادقانه:** Forge خودش مدلِ زبانی ندارد و کلیدِ API نمی‌خواهد؛ وظیفه‌اش جمع‌کردن و یکدست‌کردنِ ابزارهاست. برای تولیدِ واقعیِ پاسخِ هوش‌مصنوعی باید دست‌کم یکی از ابزارهای پشتیبان روی سیستم نصب باشد.

نسخهٔ **0.1.0** است — یعنی اولین نسخهٔ قابل‌استفاده، نه محصولِ نهایی.

| بخش | وضعیت |
|---|---|
| رابط، چت، فرمان‌ها، عامل‌ها | ✅ فعال |
| Godmode (محتوای وارداتیِ فرمان‌ها و عامل‌ها) | ✅ فعال |

## ۶. منشأ و مجوز

- محتوای فرمان‌ها و عامل‌ها از پروژهٔ [Godmode](https://github.com/patrickking67/godmode) وارد شده (Apache-2.0)؛ هر فایل بالای خودش نشانیِ منبع و مجوز را دارد.
- وابستگی‌های رابط و سرور (React، Vite، Tailwind، Motion و …) همگی MIT.
- مخزنِ میزبان (یک انشعاب از Chat2DB) از نسخهٔ ۵٫۳٫۰ به بعد مجوزِ آپاچیِ **اصلاح‌شده** دارد: استفادهٔ شخصی و درون‌سازمانی آزاد است، اما ارائهٔ آن به‌عنوان محصول یا سرویسِ بیرونی نیاز به اجازهٔ تجاری دارد. پوشهٔ `forge/` مستقل از کدِ Chat2DB است، اما هنگامِ انتشارِ عمومی بهتر است این نکته لحاظ شود.

## English TL;DR

**Forge** is a free, open-source Windows desktop app that unifies several open-source AI coding tools — **jcode**, **Soup**, and **Godmode** — into a single RTL window instead of scattered terminals. It gives you a streaming chat, nine reusable slash commands (`/genesis` to build a feature, `/exorcise` to debug a failing test, `/judgment` to review a pull request, and more), plus automatic skill routing across a 14-skill corpus and five specialised subagents.

Built with Tauri 2 (small installer), a React/Vite/Tailwind front end driven by a design-token system, and an embedded Node server bundled with its own `node.exe`. Each external tool sits behind an adapter reporting `ready` / `degraded` / `missing`, so a missing tool degrades gracefully instead of crashing the app. Note that Forge is an orchestrator, not a model: it needs at least one backing tool installed to produce AI output.
