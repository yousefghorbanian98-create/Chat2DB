# handoff/ — پیام‌های آمادهٔ کپی برای نشستِ بیلدر

این پوشه عمداً از `share/` (گزارش‌ها و پروندهٔ شواهدِ ممیزی) و از `audit/`
(اسکریپت‌ها و شاهدِ خام) **جدا** است. هرچه اینجاست یک چیز است:
**متنِ کاملی که باید عیناً در نشستِ بیلدر کپی شود** — خودکفا، بدونِ نیاز به
پیوند، فایلِ بیرونی یا دسترسیِ شبکه.

## چرا متنِ کامل و نه پیوند

یک بار به‌جای کپی‌کردنِ متن، به آن **ارجاع** دادم («§۲‑الف را ببین») و کلِ
`WP 0.9` یک دورِ کامل بلاک شد، چون بیلدر فقط چیزی را می‌بیند که در نشستش کپی شده.
پس قاعدهٔ این پوشه این است: **هرچه بیلدر برای اجرای یک WP لازم دارد، باید داخلِ
همین یک فایل باشد.** دو هنرپیشهٔ اصلی (پیکربندیِ TOML و اسکریپتِ پذیرش) به همین
دلیل داخلِ خودِ پیام‌اند، و بایت‌به‌بایت با مرجع‌هایشان در `audit/` یکسان‌اند:

- `audit/ruff-recommended.toml`
- `audit/verify-addendum-gates.sh`

اگر روزی این دو مرجع تغییر کردند، **باید** بلوکِ معادلشان در این پیام هم عوض شود؛
وارسیِ یکسانی با این دو فرمان انجام می‌شود:

```bash
python3 - <<'PY'
import pathlib, re, tomllib
t = pathlib.Path('handoff/MP-BUILDER-HANDOFF-A1.3.md').read_text(encoding='utf-8')
cfg = re.search(r'```toml\n(.*?)\n```', t, re.S).group(1)
sc  = [b for b in re.findall(r'```bash\n(.*?)\n```', t, re.S) if 'گیت‌های عددی' in b][0]
tomllib.loads(cfg)
print('TOML یکسان:', cfg == pathlib.Path('audit/ruff-recommended.toml').read_text(encoding='utf-8').rstrip('\n'))
print('اسکریپت یکسان:', sc == pathlib.Path('audit/verify-addendum-gates.sh').read_text(encoding='utf-8').rstrip('\n'))
PY
```
