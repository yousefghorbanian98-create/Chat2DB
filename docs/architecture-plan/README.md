# نقشه مهندسی معماری — مجتمع مسکونی-تجاری ۴ طبقه روی پیلوت

**کد املاک:** ۲-۰۹-۰۲۴۴۷۹-۸-۰۰۰۰ | **موقعیت:** اصفهان، اداره شهرداری منطقه ۱، دوشاخه کوی مصباح
**عرصه:** ≈۶۰۰ m² (چاپ کاداستر هاشورخورده) | **مجاز ساخت دستور نقشه:** ۵۴۲٫۳۸ m²
**تراکم مصرفی طرح:** ۵۳۵٫۵ m² (حاشیه ۶٫۹ m²) | **تاریخ:** ۱۴۰۵/۰۶/۲۴

---

## خلاصه طرح (نسخه ۲ — طبق درخواست کارفرما)

| تراز | فضاها | مساحت |
|---|---|---|
| **پیلوت (همکف)** | **۳ مغازه** (هر یک ۴٫۹×۳٫۸) + پارکینگ سرپوشیده ۴ خودرو + پله/آسانسور/لابی + مانور | پلیت ۱۸٫۶۰×۱۲٫۰۰ = ۲۲۳٫۲۰ m² (اشغال ۳۷٫۲٪) |
| **۱ تا ۴ (مسکونی)** | هر طبقه ۱ واحد ۲خوابه ۷۰٫۵ m² مفید + پله/آسانسور/لابی | ۴ × ۱۱۱٫۵۵ = ۴۴۶٫۲۰ m² |
| **بام** | باکس پله + جان‌پناه | — |

- **مغازه‌ها** رو به معبر اصلی ۲۴ متری (شرق) با ویترین کامل؛ ورودی پیاده ساکنین از کوی شمالی؛ ورود خودرو به پارکینگ از کوی جنوبی — تفکیک کامل سه نوع تردد.
- **تراکم:** ۴۴۶٫۲ (مسکونی) + ۵۵٫۶ (مغازه) + ۲۷٫۷ (مشاعات پیلوت) + ۶٫۰ (بالکن ۵۰٪) = **۵۳۵٫۵ ≤ ۵۴۲٫۳۸ ✔**

## نحوه استفاده

1. **وب‌اپ:** این پوشه را با هر وب‌سرور استاتیکی باز کنید (مثلاً `python3 -m http.server 8080`) → `index.html`
   - تب‌ها: پلان سایت | پیلوت | پلان تیپ | **مدل سه‌بعدی تعاملی** (Three.js، چرخش/زوم، سوییچ طبقات، خروجی GLB) | گزارش انطباق
2. **اتوکد:** فایل `exports/plan.dxf` (R2018، واحد متر، لایه‌بندی: WALL-EXT / WALL-INT / DOOR / WINDOW / SHOP / PARKING / STAIR / SITE / DIM …)
3. **تصاویر سریع:** `renders/*.png` (سایت، پیلوت، تیپ، ایزومتریک)

## به‌روزرسانی ابعاد زمین

ابعاد چاپ کاداستر با وضوح محدود خوانده شد و پلی‌گون به ۶۰۰ m² مقیاس شده است.
پس از نقشه‌برداری رسمی، فقط `js/data.js → parcel.basePts` را ویرایش کنید و:

```bash
node -e "const P=require('./js/data.js');require('fs').writeFileSync('tools/plan_data.json',JSON.stringify(P))"
python3 tools/verify.py        # اعتبارسنجی خودکار همه ضوابط
python3 tools/render_png.py    # رندر مجدد PNG
python3 tools/export_dxf.py    # خروجی مجدد DXF
```

## ساختار

```
architecture-plan/
├── index.html            ← وب‌اپ اصلی (RTL فارسی)
├── css/style.css
├── js/
│   ├── data.js           ← تک‌منبع حقیقت هندسه (JSON-like)
│   ├── plans.js          ← رندر SVG پلان‌ها (مقیاس ۱:۱۰۰)
│   ├── viewer3d.js       ← مدل سه‌بعدی Three.js + خروجی GLB
│   └── main.js           ← ناوبری + گزارش انطباق
├── tools/
│   ├── verify.py         ← اعتبارسنجی خودکار (ezdxf لازم ندارد)
│   ├── render_png.py     ← رندر PNG (matplotlib)
│   ├── export_dxf.py     ← خروجی DXF اتوکد (ezdxf)
│   └── plan_data.json    ← خروجی JSON داده‌ها
├── renders/  ← PNG های آماده
└── exports/  ← plan.dxf
```

## ضوابط رعایت‌شده (منابع اوپن‌سورس)

- سطح اشغال ≤ ۶۰٪، پیلوت ≤ ۳۰٪ مساحت، زیرزمین/فضای باز پیلوت خارج از تراکم — [ضوابط شهرداری در طراحی معماری](https://doctorjavaz.com/ضوابط-شهرداری-در-طراحی-معماری/) و [موفق مجوز اصفهان](https://mojavezisfahan.ir/building-overlooking/)
- راه‌پله ≥ ۱٫۱۰ m (بند ۳-۱-۴-۴-۴ مبحث ۳)، آسانسور ≥ ۱٫۶۰×۲٫۰۰، لابی ۱٫۵۰×۱٫۵۰ — [planyab](https://planyab.com/ضوابط-طراحی-پله-و-آسانسور/)
- شیشه ≥ ۱/۸ کف (مبحث ۴، بند ۵-۴-۳-۳) — [omranpooya](https://omranpooya.com/construction/procedure/general-requirements/gr-5)
- بالکن واحد < ۱۰۰ m² اصفهان ≥ ۳ m² — [markazeahan](https://www.markazeahan.com/definition-construction-balconies-building/)
- پارکینگ ۲٫۵×۵، مسیر ۳ m، ارتفاع ۲٫۲۰ — [ahanjam](https://ahanjam.com/parking-regulations/) و [tka-eng](https://tka-eng.com/parking-ordinary/)

## ابزارهای اوپن‌سورس

SVG خالص + **Three.js** r128 (نمای ۳بعدی، OrbitControls، GLTFExporter) + **ezdxf** (DXF) + **matplotlib** (PNG) + فونت **Vazirmatn**. بدون نیاز به نرم‌افزار تجاری.

## ⚠️ سلب مسئولیت

این بسته **پیش‌طرح فاز ۲** است و جایگزین نقشه‌های مهندسین رسمی (معماری/سازه/تاسیسات/برق) نیست. کنترل نهایی ضوابط (تعداد طبقات مجاز پروانه، پارکینگ تجاری، ارتفاع، مشرفیت) با شهرداری و نظام مهندسی است.
