## 1. باگی که در همین بازبینی پیدا شد — و درسش

```
FAIL src/hooks/useWorkoutLog.test.ts
  expected session_date "2026-08-30", received "2026-09-06"
```

تست، تاریخ *امروز* را هارد-کد کرده بود. یعنی از ۳۱ آگوست به بعد، سوئیت **همیشه قرمز** بود.
هیچ‌کس متوجه نشد چون CI تست اجرا نمی‌کند (سند ۰۷ §۱).

**رفع:** ساعت با `vi.useFakeTimers({ shouldAdvanceTime: true })` فریز شد.

**سه درس الزام‌آور:**
1. **هیچ تستی نباید به ساعت واقعی، منطقهٔ زمانی یا شبکه وابسته باشد.** ساعت را همیشه فریز کنید.
2. **CI باید تست اجرا کند** — تست‌هایی که فقط روی لپ‌تاپ توسعه‌دهنده اجرا می‌شوند، وجود ندارند.
3. یک job شبانه با تاریخ‌های آینده (`libfaketime` یا `TZ` متفاوت) اضافه کنید تا
   بمب‌های ساعتی مشابه پیدا شوند. این پروژه با تقویم جلالی، مستعد این باگ است.

## 3. تست‌های طلایی (Known-Answer) — نقطهٔ قوت

پروژه این را درست انجام داده و باید گسترش یابد:

| موتور | لنگر | وضعیت |
|-------|------|--------|
| JP7 / Siri | ۴ fixture داخلی + مثال منتشرشدهٔ بیرونی | ✅ |
| تقویم جلالی | ۹ لنگر در برابر `jdatetime` | ✅ |
| BMR/TDEE/ماکرو | محاسبهٔ دستی راستی‌آزمایی‌شده | ✅ |
| فیلتر مصدومیت | — | 🔴 **لنگر ندارد** |
| قیمت‌گذاری/تناسب بستهٔ عضویت | — | 🔴 ندارد |

**اولویت:** فیلتر مصدومیت **قلب ایمنی محصول** است (C5) و هیچ جدول معلوم‌الجواب ندارد.
بسازید:
```
| مصدومیت        | حرکت            | انتظار      |
|----------------|-----------------|-------------|
| زانوی راست حاد | اسکات با هالتر  | مسدود       |
| زانوی راست حاد | پرس سینه        | مجاز        |
| شانهٔ چپ مزمن  | پرس سرشانه      | مسدود       |
| شانهٔ چپ برطرف | پرس سرشانه      | مجاز        |
| کمر + بدون رک  | ددلیفت          | مسدود (دوگانه) |
```
هر ردیف یک تست. اگر روزی کسی منطق فیلتر را «بهینه» کرد، این جدول جلویش را می‌گیرد.

## 6. کیفیت پوشش، نه درصد پوشش

پوشش ۹۰٪ می‌تواند دروغ بگوید. سه معیار مکمل:

1. **تست جهش (Mutation testing):** `mutmut` روی `app/core/`. اگر تغییر `>` به `>=`
   هیچ تستی را نشکند، تست‌ها فقط کد را «لمس» می‌کنند نه «بررسی».
   هدف: امتیاز جهش ≥ ۷۰٪ روی موتورهای عددی.
2. **تست ویژگی‌محور (property-based):** `hypothesis` برای JP7 —
   «برای هر ورودی معتبر، ۰ < درصد چربی < ۷۵ و جرم چربی + جرم بدون چربی = وزن».
3. **تست جهش تاریخ:** سوئیت را با `TZ=Pacific/Kiritimati` و `TZ=UTC` اجرا کنید.
   با تقویم جلالی، اختلاف روز حتماً چیزی را می‌شکند.
