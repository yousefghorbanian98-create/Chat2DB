# LOOP FILE — محل اجرای حلقه

حلقهٔ ساختِ **اپ ویندوزی ارکستریتور** آماده و جاسازی شده است.

محل فایل‌ها:

```
docs/WINAPP_LOOP_v1.0/BLUEPRINTS.md    ← انتخاب شده: قالب A + D
docs/WINAPP_LOOP_v1.0/LOOP_DESIGN.md   ← دو لوپ (FE / BE) + دم مشترک (INT)
docs/WINAPP_LOOP_v1.0/TRACKER.md       ← ۶۵ آیتم با شناسه
```

## انتخاب‌های ثبت‌شده

| مورد | انتخاب |
|---|---|
| قالب ساختاری | **A + D** (ارکستریتور سبک + طراحی‌محور) |
| ساختار لوپ | **LOOP-FE** و **LOOP-BE** مجزا + **LOOP-INT** برای ادغام |
| سطح خودکاری | Autopilot — بدون توقف میانی |
| خروجی نهایی | نصب‌کننده exe/msi از GitHub Actions روی windows-latest |
| محصول | نام کاری **Forge** در مسیر `forge/` |

## وضعیت

```
✅ ۲۰ منبع بررسی شد
✅ قالب انتخاب شد (A + D)
✅ معماری دو لوپ طراحی و جاسازی شد
✅ گیت‌ها و نگهبان‌ها تعریف شد
✅ ترکر ساخته شد (۶۵ آیتم)
⬜ اجرا
```

**هیچ کدی نوشته نشده، هیچ وابستگی‌ای نصب نشده، هیچ گیتی اجرا نشده است.**
