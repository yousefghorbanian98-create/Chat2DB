# نقشهٔ ارسالی کاربر — مرجع حفظ شناسه، عنوان و مرز پذیرش

**منبع:** متن کاملِ طرحی که مالک در همین گفتگو برای مقایسه و اصلاح ZIP فرستاد؛ 2026-11-24. این فایل رونویسی جدول‌های آن پیام با رفع escapeهای ظاهری Markdown است. این جدول‌ها گزارش اجرای محصول نیستند.

**شمارش واقعی جدول‌ها:** ۵۰ میکرولوپ در شش فاز: ۶ + ۸ + ۵ + ۱۶ + ۸ + ۷. آخرین شناسه `PWA-56` است، اما شناسه‌ها پیوسته نیستند و `PWA-3A` تا `PWA-3F` نیز دارند. هیچ شناسه‌ای برای رسیدن به عدد ۵۶ ساخته، حذف، ادغام یا بازشماره‌گذاری نشده است.

**مسیر منتخب برای handoff اصلاح‌شده:** `mp-app/studio/` پایهٔ PWA یکپارچهٔ React شود؛ صفحات موجود کارکنان حفظ و تطبیق داده شوند؛ تجربه‌های عضو از Flutter به‌صورت تدریجی به همین PWA منتقل شوند؛ فایل‌ها و گیت‌های Flutter/Android حذف یا خاموش نشوند. این انتخاب، مجوز تغییر نقش‌ها، grants، DB، پرداخت، آفلاین یا انتشار محصول نیست؛ baseline انتشار باید در PWA-00/ADR ثبت شود.

## سفرهای انتهابه‌انتها — مرجع پذیرش متن ارسالی

1. **عضو:** OTP → پروفایل خودش → برنامهٔ تأییدشده → ثبت اجرای واقعی/feedback → بارگذاری مجدد صفحه و مشاهدهٔ وضعیت سرور.
2. **مربی:** ورود → انتخاب عضو مجاز → ارزیابی → پیش‌نویس برنامه → بازبینی و تأیید با دلیل → همان نسخه برای عضو.
3. **حضور:** عضو/پذیرش → QR → اعتبارسنجی server-side → رد token منقضی یا تکراری.
4. **مالی:** عضو رسید را ارسال کند → کارکنان مجاز آن را بررسی کنند → نتیجه و audit ثبت شود؛ **ارسال رسید به معنی تأیید بانکی نیست.**
5. **امنیت:** عضو A نتواند صفحه، API، رسید، پیام یا دادهٔ عضو B را ببیند؛ تغییر URL یا مخفی‌بودن دکمه نباید این قاعده را عوض کند.

## مرزهای سراسری متن ارسالی

- Forge → Inspect → Normalize → Next؛ یک نتیجهٔ قابل‌آزمون در هر میکرولوپ؛ ۹ حوزهٔ قرارداد برای هر کارت، نه یک‌بار برای کل فاز.
- سؤال‌های کوچک و برگشت‌پذیر در محدودهٔ تأییدشده ثبت و انجام شوند؛ ابهام واقعی فقط کار وابسته را BLOCKED کند؛ سؤال‌های مالک در یک بسته جمع شوند.
- حداکثر سه تلاش برای خطای تکراری؛ گیت و تست تضعیف نشود؛ PASS بدون شاهد ممنوع؛ review/merge در checkpointهای دسته‌ایِ مصوب و همچنان انسانی.
- ابزارهای فعلی Finn، GitHub Actions، Semgrep و Gitleaks بازاستفاده شوند؛ ECC حذف شده است. جایگزینی orchestrator با LangGraph/OpenHands، CI دوم یا telemetry بیرونی مجوز پیش‌فرض ندارد.
- Spec Kit، Container Use، AgentLint، in-toto و Promptfoo فقط در صورت نیاز مشخص و ارزیابی هم‌پوشانی/مجوز مطرح شوند؛ نصب کورکورانه لازم نیست. Langfuse با trace حساس انتخاب پیش‌فرض نیست.
- مدل ۳نقشی، session/storage، آفلاین، topology و قرارداد انتشار نیازمند owner gate مستقل‌اند. تصمیم React به معنی تأیید این موارد نیست.
