# نصب و اجرا — بستهی آمادهی Motion Package

این بسته شامل build نهایی است.

نیازی به نصب وابستگی یا build نیست.

## پیشنیاز

Node.js نسخهی ۱۸ یا بالاتر:

```
https://nodejs.org
```

## اجرا

ویندوز:

```
دوبار کلیک روی start.bat
```

macOS / Linux:

```
./start.sh
```

اگر خطای دسترسی داد:

```
chmod +x start.sh
```

## بعد از اجرا

مرورگر خودکار باز میشود:

```
http://127.0.0.1:8889
```

اگر باز نشد، خودت آدرس را باز کن.

## تأیید سوییچ

```
تنظیمات ← Motion Package
```

دو کارت:

```
Data Cosmos
```

و

```
Hyperreal
```

روی هرکدام کلیک کن — انتخاب بهصورت خودکار ذخیره میشود و بعد از رفرش میماند.

## پورت دیگر

```
PORT=8890 node serve-dist.cjs
```
