## ۱) حال‌وهوا و بافت بصری

ابزارِ توسعه‌دهنده، ساکت و دقیق. صفحه حرف نمی‌زند؛ داده حرف می‌زند.
تراکم بالا اما آرام: هیچ سایه‌ای نیست، عمق فقط با خطِ مویی (hairline) ساخته می‌شود.
وزنِ نمایشی همیشه ۴۰۰ است — صدای مجله، هرگز بولد.

### امضای بصری — تایم‌لاینِ عامل (۵ پاستیل)

این پنج رنگ **فقط** برای مراحلِ اجرای عامل به کار می‌روند و هرگز به‌عنوان رنگِ

## ۳) قواعد تایپوگرافی

نمایشی همیشه **وزن ۴۰۰**. مونو روی هر سطحِ کد.

| توکن | اندازه / وزن / ارتفاع / فاصلهٔ حروف |
|---|---|
| `display-lg` | ۳۶px / ۴۰۰ / ۱٫۲ / −۰٫۷۲px |
| `display-md` | ۲۶px / ۴۰۰ / ۱٫۲۵ / −۰٫۳۲۵px |
| `display-sm` | ۲۲px / ۴۰۰ / ۱٫۳ / −۰٫۱۱px |
| `title-md` | ۱۸px / ۶۰۰ / ۱٫۴ |
| `body-md` | ۱۶px / ۴۰۰ / ۱٫۵ |
| `body-sm` | ۱۴px / ۴۰۰ / ۱٫۵ |
| `caption-uppercase` | ۱۱px / ۶۰۰ / ۱٫۴ / ۰٫۸۸px |
| `code` | ۱۳px / ۴۰۰ / ۱٫۵ — JetBrains Mono |
| `button` | ۱۴px / ۵۰۰ / ۱٫۰ |
| `nav-link` | ۱۴px / ۵۰۰ / ۱٫۴ |

فونت‌ها: Inter (متن) و JetBrains Mono (کد) — هر دو از طریق Google Fonts.

> **یادداشتِ اجرا:** این جدول تا ۲۰۲۶-۰۹-۰۲ فقط روی کاغذ بود — کامپوننت‌ها
> اندازه‌ی دلخواه (`text-[22px]` و …) داشتند. از این تاریخ هر ردیفِ بالا به‌صورت
> یک utility در `src/styles/index.css` پیاده‌سازی شده (`text-display-md`،
> `text-body-sm`، `text-caption`، `text-code` و …) و تستِ رندر وجودِ
> اندازه‌ی دلخواه در خروجی را خطا می‌گیرد.

## ۴) استایل قطعات

- **دکمهٔ اصلی:** نارنجیِ برند، شعاع ۸px، ارتفاع ۴۰px
- **دکمهٔ ثانویه:** سطحِ کارت + خطِ موییِ ۱px
- **دکمهٔ سوم:** متنِ ساده با پیکان
- **کارت:** فقط خطِ مویی، بدون سایه
- **قرصِ مرحله:** فقط برای مراحلِ عامل و نشان‌ها — شعاعِ pill
- **فیلد ورودی:** سطحِ کارت + خطِ مویی، ارتفاع ۳۶px

## ۵) اصول چیدمان

مقیاسِ فاصله با پایهٔ ۴px:
`xxs ۴ · xs ۸ · sm ۱۲ · base ۱۶ · md ۲۰ · lg ۲۴ · xl ۳۲ · xxl ۴۸ · section ۸۰`

سه ستون در حالت دسکتاپ: فهرست (ثابت ۲۸۰px) · جریانِ اصلی (منعطف) · پنلِ کناری (۳۶۰px، قابل بستن).

## ۶) عمق و ارتفاع

**بدون سایه.** لایه‌بندی فقط با تضادِ سطح‌ها و خطِ مویی:

1. تخت / کف
2. پنل
3. کارت
4. کارتِ معکوس (برای موردِ برجسته)

## ۷) بایدها و نبایدها

**باید**
- هر رنگ از توکن بیاید، نه از مقدارِ ثابت در کد
- کد همیشه با JetBrains Mono
- مراحلِ عامل با پاستیل‌های تایم‌لاین
- وزنِ نمایشی ۴۰۰ بماند

**نباید**
- سایه (box-shadow) برای عمق
- استفاده از پاستیل‌های تایم‌لاین خارج از نمایشِ مراحل
- بولد کردنِ عنوان‌های نمایشی
- رنگِ مستقیم در کلاس‌ها (مثل `text-[#f54e00]`)

## ۸) رفتار واکنشی

| نام | عرض | تغییر |
|---|---|---|
| موبایل | < ۶۴۰px | ستون‌ها جمع می‌شوند؛ پنلِ کناری تمام‌صفحه |
| تبلت | ۶۴۰–۱۰۲۴px | پنلِ کناری به صورت لایه روی محتوا |
| دسکتاپ | ۱۰۲۴–۱۲۸۰px | سه ستون کامل |
| عریض | > ۱۲۸۰px | محتوا تا ۱۴۴۰px محدود می‌شود |

هدفِ لمسی: دکمهٔ اصلی ۴۰px، دکمهٔ دانلود ۴۴px.

## ۹) راهنمای پرامپت برای عامل

هر قطعهٔ UI جدید باید:
1. رنگ‌ها را فقط از توکن‌های بالا بخواند
2. مراحلِ عامل را با پاستیل‌های تایم‌لاین نشان دهد
3. بدون سایه باشد
4. عنوان‌های نمایشی را با وزن ۴۰۰ نگه دارد
5. کد را با JetBrains Mono نمایش دهد
