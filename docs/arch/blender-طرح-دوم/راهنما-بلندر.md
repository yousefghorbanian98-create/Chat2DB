# ساختِ رندر با بلندر — طرح دوم — تماماً مسکونی

## اجرا
۱) بلندر را باز کنید → زبانهٔ **Scripting** → **Open** → `build_scene.py` → **Run Script**
۲) یا از خطِ فرمان:
```
blender --background --python build_scene.py -- --render --samples 128 --res 1280x800
```

## مشخصاتِ این طرح
| ویژگی | مقدار |
|---|---|
| طبقات | پیلوتِ پارکینگ + ۳ طبقهٔ مسکونی |
| واحدها | 12 واحد · هر واحد 65.4 m² بسته + ایوان |
| ارتفاع | 12.30 m |
| تراکم | 217.9٪ |
| پارکینگ | 13 فضا |

## تنظیماتِ پیشنهادی برای کارتِ ضعیف (GTX 1650)
```
--samples 128 --res 1280x800
```
سپس اگر روان بود:
```
--samples 256 --res 1920x1200
```
کلیدِ ماجرا «کم‌نمونه + حذفِ نویز» است: OpenImageDenoise روی CPU اجرا می‌شود
و به کارتِ گرافیک ربطی ندارد.

## برای خروجیِ حرفه‌ای (به ترتیبِ اهمیت)
۱. آدم، ماشین، درخت و چراغ اضافه کنید — بیشترین تفاوتِ رندرِ آماتور و حرفه‌ای
۲. مصالحِ بافت‌دار از polyhaven.com (رایگان، CC0)
۳. زمانِ خورشید: `--hour 17` برای نورِ گرم، `--hour 9` برای نورِ صبح
۴. پس‌پردازش در زبانهٔ Compositing

**شرافتِ روش:** این اسکریپت در محیطی نوشته شده که بلندر در آن اجرا نمی‌شود،
بنابراین اجرایش را تست نکرده‌ام — فقط نحو و داده‌هایش بررسی شده است.
اگر خطا داد، متنِ خطا را بفرستید تا همان لحظه درستش کنم.
