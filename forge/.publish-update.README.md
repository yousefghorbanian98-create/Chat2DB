# ‎.publish-update‎

وجودِ این فایل یعنی **اجازه می‌دهیم CI بسته‌ی به‌روزرسانیِ تفاضلی را روی همان
Release منتشر کند.** محتوایش فقط نامِ برچسب (tag) است.

چرا این فایل به‌جای یک مرحله در workflow؟ نوشتن در ‎.github/workflows/**‎ از
محیطِ توسعه مجاز نیست (HTTP 403). اسکریپتِ ‎scripts/publish-update.mjs‎ همان
کار را می‌کند، با این قیدها:

- فقط وقتی ‎CI=true‎ باشد اجرا می‌شود (هرگز روی دستگاهِ توسعه‌دهنده)؛
- فقط همین برچسب را به‌روزرسانی می‌کند؛
- از همان نشانه‌ای استفاده می‌کند که workflow با ‎permissions: contents: write‎
  در اختیار گذاشته — دسترسیِ تازه‌ای نمی‌خواهد؛
- هیچ‌وقت بیلد را خراب نمی‌کند: هر خطا فقط یک هشدار است.

**برای غیرفعال کردن کافی است این فایل را پاک کنید** — آن‌وقت بیلد فقط
نصب‌کننده را می‌سازد و چیزی منتشر نمی‌شود.
